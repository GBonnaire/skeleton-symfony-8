# Préambule 
Tu vas ajouter la liste des demandes dans la TODO List, pour chaque élément de la TODO fait :
- une analyse d'impact, 
- liste les fichiers concernés par l'impact, 
- les modifications Template, Formulaire, Base de données, Service qui vont devoir être modifier,  
- puis ensuite applique les modifications recommandées.

# Objectif
Assurer que les modifications / corrections apportées à l'application soit correctement intégrées et cohérentes dans l'ensemble de l'application
